# Changelog

## 0.1 — 2026-10-26

- Независимое геометрическое ядро AutoLISP: стороны, периметр, знаковая площадь, обход.
- Проверки дублей, замкнутости, дуг, пересечений, касаний и вырождения.
- GCT_INFO: чтение LWPOLYLINE, OCS→WCS, текстовый отчёт без изменения чертежа.
- Python-эталоны, исполняемые проверки исходника ядра и нативные CAD-фигуры.
- Целевая совместимость AutoCAD/nanoCAD; нативная проверка остаётся ручной.
